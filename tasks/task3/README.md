(0.5–1 page), user requirements (0.5–1), system requirements, functional and non-functional

| Criterion | Points | Full marks when |

| Functional requirements | 4 | clear, complete, unambiguous |
| Non-functional requirements | 4 | clear, complete, unambiguous |
| Functional vs non-functional | 3 | well distinguished |
| AI-specific | 3 | clearly indicated and relevant |
